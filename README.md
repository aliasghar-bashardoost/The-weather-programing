# Weather App 🌤️

A desktop weather application built with **Python** and **wxPython**, using the **Open-Meteo API** for real-time weather data.

## Features
- Current weather conditions (temperature, feels-like, description)
- Humidity, wind speed, and atmospheric pressure
- Air quality index
- Sunrise and sunset times
- Search by city/location
- Recent search history
- Favorite cities
- Unit conversion (°C / °F)
- Standalone .exe build (no Python installation required)

## Built With
- Python
- wxPython (GUI)
- Open-Meteo API
- PyInstaller (for .exe packaging)
